## 1. 项目概述

| 项目 | 内容 |
|---|---|
| 名称 | 福瑞快打 |
| 游戏类型 | 竖屏休闲动作闯关（自动战斗 + 大地图探索 + Roguelike 升级 + Boss 战） |
| 平台 | H5（纯前端 Canvas，可打包为 Windows exe） |
| 当前模式 | **无尽模式**（生存波次制，每 10 波 Boss，阵亡结算） |

| 局外养成 | 金币解锁武器/装备/物品/宠物 + 宠物等级·升星·天赋·词条；存档落盘本地 JSON |

- **打包**：已配置 Electron（`package.json` + `electron/main.js` + `build/icon.png`），本机运行 `npm install && npm run dist` 生成 Windows exe。

## 2. 主菜单（局外养成）

## 3. 伤害模型（四种类型）

| 伤害类型 | 字段 | 归属 |
|---|---|---|
| 子弹伤害 | `bulletDamage` | 武器（步枪/散弹/机枪/狙击枪） |
| 元素伤害 | `elementalDamage` | 元素类：火球、雷电、冰刺、燃烧（火焰） |
| 召唤物伤害 | `summonDamage` | 召唤物：镰刀、飞剑 |
| 宠物伤害 | `petDamage` | 龙蛋 / 火焰精灵（其点燃仍属元素伤害） |

> **元素类与召唤物彻底分开**：火球 / 雷电 / 冰刺只吃**元素伤害**加成；镰刀 / 飞剑只吃**召唤物伤害**加成。两类都走「升级卡加算 + 进化独立乘区」的同一套算法。

**乘区规则（参考 PoE 的「增加 / 更多」、Vampire Survivors 的同类加算）**

```
最终伤害 = 基础值 × (1 + 同类加成之和) × 独立乘区
```

- **同类百分比一律「加算」**：所有"+30% 子弹伤害""-30% 元素伤害"都塞进同一加算区，最后只乘一次。
- **只有独立来源才进乘算区**：局外装备（力量护符 ×1.15）、进化终极形态（如死神镰刀 ×1.4）。
- **减益进同一加算区，并留下限**：`DMG_FLOOR = 0.3`，任何一路伤害最低保留 30%。
- **转换卡限次**：子弹→元素的「元素法师」每局最多 2 次。
- 召唤物 / 宠物伤害同理：升级卡进加算区（`dmgAdd`），进化进独立乘区（`dmgMore`），最终折算成 `dmgMul`。
- **「数量 +1」类卡牌统一带 ×0.9 独立乘区**（飞剑 / 火球 / 闪电 / 冰刺 / 镰刀数量卡），避免纯线性膨胀。

| 举例（元素法师 ×2 + 强力子弹 ×3 + Boss 元素 ×2） | 旧（连乘） | 现（加算） |
|---|---|---|
| 子弹倍率 | ×0.269 | ×0.3（触下限） |
| 元素倍率 | ×5.76 | ×3.4 |

**宠物元素乘区下限**：宠物弹丸伤害 = 基础 × 宠物乘区 × `stats.petDamage` × `max(1, stats.elementalDamage)` —— 元素加成能放大宠物，但「元素归零」类 Boss 奖励不会把宠物伤害清零。

**其它进加算区的属性**

| 属性 | 说明 |
|---|---|
| 易伤 `stats.vuln` | 敌人受到的伤害 ×(1 + Σ易伤)，命中结算处只乘一次（嗜血 +20%/张） |
| 吸血 `stats.lifesteal` | 按实际造成伤害的百分比回复队伍血池（嗜血 1%/张；镰刀饮血与死神镰刀另有独立来源） |
| 回血 `stats.regen` | 固定值，回血宝珠 +2/s，不参与百分比乘区 |
| 触发型回血 `stats.bloodOrb` | 血珠：造成伤害时 5% 概率回复该次伤害的 5% |

## 4. 战斗系统

**小兵（共享血池）**：初始 1 名，站桩跟随队形。

- **血条共享**：所有小兵共用一条队伍血池 `squadHp`，上限 = 小兵数 × 单个小兵血量（`小兵初始生命 100 × 生命上限加成`）。
- 所有小兵头顶显示的都是**同一条队伍血条**；伤害统一结算进血池，**不会单独死亡**。
- **掉一格（= 一个小兵的血量）就消失一个小人**：血池不足一个小兵血量时对应数量的小兵当场消失（红色粒子），血池上限同步下调；血池见底则全部消失、判定失败。
- 受伤免疫（护盾 / 免疫时长 / 闪避）统一作用于队伍。
- 范围伤害（自爆怪爆炸、Boss 冲刺）对共享血池**只结算一次**。

### 4.2 召唤物之一：镰刀（近战护卫 · 可攻可防）

**机制**：刀刃环绕角色旋转，接触敌人即造成伤害。

| 参数 | 值 | 说明 |
|---|---|---|
| 伤害 | 10 | 单次 |
| 环绕半径 | **52** | 固定，**不随体型变化**（体型卡不再把刀推远） |
| 环绕速度 | 3.5 rad/s | 约 1.8s 一圈 |
| 刀刃体积 | 12 | 渲染大小 |
| 判定半径 | **24** | 接触判定 = 判定半径 + 敌人半径，含刀刃容差 |
| 每敌受击冷却 | **0.16s** | 一次扫过可命中多次 |
| 阻挡子弹 | 10% | 概率挡掉碰到的敌方子弹（可升至 45%） |

**有效范围**：约 **14 ~ 90px**（以 52 为圆心、判定 24 + 普通敌人半径 14 计）。贴身近战怪（约 25~55px）与环绕轨道都在覆盖内；**120px 外打不到**（纯近战定位）。

**轨道锚点**：镰刀的逻辑判定、敌方子弹阻挡和绘制统一使用当前可见小兵队形中心。小兵跟随移动目标点存在插值时，刀环仍贴着角色，不会在移动方向前方漂移；无小兵时回退到 `squad` 中心。

| 镰刀卡 | 效果 |
|---|---|
| 数量 +1 | 多一把环绕刀刃（**只扩大覆盖面，不降低伤害、不叠加单体频率**） |
| 飞行速度 +20% | 转速更快（每圈扫过次数更多） |
| 伤害 +30% | 同类相加 |
| 变大 | 刀刃体积与判定 ×1.3（环半径不变，更容易扫到贴身敌人） |
| **饮血 +10%** | 镰刀造成伤害的 10% 回复队伍生命（最多叠 2 次） |
| 阻挡子弹 +15% / +20% | 递进升级，最高 45% |
| 击退 | 命中击退敌人（1 秒击退抗性；Boss 免疫） |

**核心机制**

1. **沿途贯穿**：按本帧位移线段做穿身判定（点到线段距离 < 剑身判定 + 敌人半径），**一趟冲刺路径上的敌人全部结算**，同一趟每只只吃一次；冷却未就绪时只穿身不结算，但仍会结束这一趟（避免贴着敌人反复穿刺）。
2. **多柄目标独立**：每帧先给各剑已锁定目标登记占位（同一敌人只归一柄），抢不到的重新索敌；索敌优先级 = 未被占用 > 只有自己刚穿过的那个 > 刚被别的剑穿过的。敌人少于飞剑时允许共享。
3. **节奏错峰**：初始冷却按柄序等分（第 i 柄 = `i/柄数 × 0.6s`），多柄不会同一时刻撞上去。
4. **护身剑阵**：敌人进到小队 80px 内时，在外追击的剑立刻放弃远处目标回身护主（不打断正在进行的贯穿滑行），剑身外圈闪一圈蓝环。
5. **惯性滑行 + 折返**：贯穿后沿剑尖滑行 0.22s → 拉到 60px 外 → 按「剩余冷却刚好够冲回去」的时机折返（用冲到接触范围的距离反推），保证每次折返都能结算伤害、不空穿。
6. **贯穿打击反馈**：命中在敌人身上留下沿剑身方向的细长白光（0.2s 淡出），不再绘制扩散圆环。使用 `performance.now()` 的绝对过期时间，在主循环及绘制前清理；顿帧、暂停、升级或后台恢复均不会让旧斩痕残留。命中瞬间 0.02s 顿帧（带 0.25s 节流）+ 轻微震屏。

## 9. 数值与平衡

**成长节奏**

- 升级节奏：初始经验需求 **15**，逐级 `×1.25 + 5`（15 → 23 → 33 → 46 → 62 → 82 …）。
- 世界成长（每击败 1 个 Boss）：**经验获取 +20%**、**出怪量 +12%**（同时作用于每波怪量与出怪间隔，间隔加速上限 1.6 倍），并刷新场景植物。
- **第一个 Boss 之后，小怪与出怪随波次动态成长**：
  - 小怪血量倍率 `enemyHpScale()`：第一个 Boss 前 = 1；之后 = `1 + 0.05 × (波次 - 10) + 0.25 × (Boss 数 - 1)`。
  - 出怪倍率 `spawnScale()`：`1 + 0.12 × Boss 数`，击败过 Boss 后额外 +0.10 基础值并随波次增长（`+0.05 × max(0, 波次 - 10)`）。
- 动态难度：每击败一个 Boss 难度 +0.25（上限 3 倍），影响敌人血量/伤害/速度。
- 关键上限：闪避 60%、受伤免疫 1.5s、升级选项 6、`DMG_FLOOR = 0.3`。

| 增援 +1 代价 | 子弹加成 -10%（同类相加） |

**实测 DPS 对照**（同一测试台：只装单一来源、静止目标、无强化；单位 DPS）

| 来源 | 单体（170px） | 站位/备注 |
|---|---|---|
| 狙击枪 | 20.3 | 38 / 2.0s |
| 机枪（改后） | 19.1 | 7 / 0.35s |
| 步枪 | 17.0 | 15 / 0.9s |
| 镰刀 | **17.3** | 敌人处于 25~52px 环带；120px 外为 0 |
| 飞剑（1 柄） | 15.0 | 贯穿可同时命中多只 |
| 宠物（龙蛋 / 精灵） | 13.9 | 含点燃 |
| 冰刺 | 12.0 | 另附减速 |
| 火球 | 11.2 | 由武器命中触发，实际受武器射速限制 |
| 雷电 | 10.8 | 同上 |
| 散弹 | 9.3 | 贴脸（45px）**30.8**；远距衰减明显 |

| 群体/多柄场景 | 总量 DPS |
|---|---|
| 镰刀 · 5 只围拢 | **80.7**（≈16/只，近战群体线性叠加） |
| 飞剑 · 5 只围拢（1 柄） | 39.0（一趟贯穿平均命中 1.56 只） |
| 飞剑 · 3 柄集火单体 | **44.1**（4.9 次/秒 = 冷却上限） |
| 飞剑 · 3 柄 4 敌分散 | 30.6 |

> 结论：四把武器的基础 DPS 收敛在 17~20 的窄带内（散弹用贴脸 30.8 的峰值换远距 9.3 的短板）；局内一次获取的路线中，**镰刀（近战群体）与飞剑（远程贯穿）单体持平在 15~17**，各自在自己的场景（贴身围拢 / 远距多目标）拿到更高收益；元素三件套单体偏低但附带减速/点燃/AoE 与可放大的元素乘区。

## 10. 打击反馈 / 音效 / 操作

- 打击反馈：伤害数字、屏幕震动、命中/击杀/爆炸粒子、**飞剑贯穿斩痕 + 0.02s 顿帧**（节流 0.25s）；普通怪与首领受击 0.09s 亮色反馈、粒子拖尾、普通子弹曳光与镰刀弧形轨迹。V1.2 移除普通击杀扩散圈与飞剑斩痕圆环，保留 0.2s 短促剑光；敌人一经标记死亡便不再绘制。敌弹使用珊瑚红外圈与浅色核心，区别于己方子弹；火球爆炸、雷电、冰刺等实际技能特效保留。
- 音效：Web Audio 实时合成（噪声缓冲 + 滤波扫频 + 包络）——射击、命中、拾取、升级、爆炸、雷击、火球、冰刺、减速等；背景为简单循环音乐。
- 操作：虚拟摇杆（触屏）+ 键盘 WASD / 方向键，二者可并存。升级卡使用原生按钮，可通过 Tab 聚焦、Enter / Space 选择，并有清晰焦点描边。

## 10.2 屏幕适配

- **逻辑分辨率跟随屏幕比例**：竖屏以宽 450 为基准、横屏以高 450 为基准，另一维按真实屏幕比例换算。
  - 竖屏允许区间 16:9 ~ 22:9（450×800 ~ 450×1050），横屏为其倒数，覆盖主流手机；
  - 手机屏内**满屏显示、不留黑边、不拉伸**；超出区间（如桌面宽屏开竖屏）等比留边居中。
- **高清渲染**：canvas 后备缓冲按设备像素比（上限 2 倍）放大。
- **面板滚动**：`html/body` 禁止滚动，菜单/面板保留滚动能力并提供细滚动条；六选升级在竖屏纵向排列、横屏两列，重开升级面板和切换菜单页时回到顶部。
- 窗口尺寸或手机方向变化时自动重新适配（含防抖）。
- 遵循系统 `prefers-reduced-motion`：关闭界面入场动画、角色摇尾/呼吸/眨眼/抖耳/围巾摆动、萤火漂移与屏幕震动。

## 10.3 美术实现与视觉验证（V1.2）

- **角色**：柔和脸部曲线、分层耳廓、奶油色尾尖与毛纹、渐变虹膜/眼部高光、鼻口与胡须、衣服缝线/口袋、金属扣、靴底和枪械层次共用一套 Canvas 绘制。毛色、服装、头饰、眼睛和体型仍即时生效；小尺寸局内模型省略部分细纹，视觉重绘不修改命中半径。
- **待机动画**：尾根固定的摇尾、脚底落地的轻呼吸、每约 4.8s 眨眼、偶尔抖耳和围巾轻摆。局外预览使用独立时间；局内使用对局时间，不同队员按序错开相位，暂停/升级时角色动画冻结。动画不修改实体坐标，不调用游戏随机数；减少动态效果时固定为静止姿态。
- **敌人**：明暗渐变与落地阴影，快速怪/猎人/首领增加尖耳，精英/护盾怪/首领增加护甲标记，治疗怪增加十字标记；保留原有类型颜色、护盾环、冰冻和点燃表现。
- **场景**：苔藓、裂纹石板、碎石、萤火与青色经验晶体。静态地形缓存为 1000 × 2400 离屏画布，每帧只拷贝视口附近区域；新地图和快照恢复时使缓存失效。装饰纹理使用确定性坐标，不消耗战斗随机数。局外主题切换不会修改此缓存或世界对象。
- **资源**：`assets/forest.svg` 为仓库内原创矢量资源，其他主题背景使用本地 CSS；Electron 打包包含 `assets/**/*` 与 `themes.css`，不依赖远程字体或图片。
- **浏览器验证（2026-09-18）**：`tests/visual-smoke.html` 使用 iframe 和可读写的内存存档适配器，执行 180 帧混合战斗与真实 Canvas 绘制，共 38 项检查通过，包含原有流程、五主题切换/写入/读回、局内各状态拒绝切换、旧存档兼容、主题切换前后植物/建筑数据与地形图像不变、动画姿态、全部头饰/体型绘制、镰刀跟随可见队伍中心、Boss 冲刺 70 点独立伤害，以及实际飞剑击杀后拾取经验并暂停 350ms 再绘制时斩痕数量为 0；浏览器 error / warn 日志为 0。此记录是功能/渲染回归，不作为帧率性能基准或 DPS 测量。
- **人工视觉检查尺寸**：390 × 844、320 × 568、900 × 450；检查首页、六选卡片滚动及横屏双栏。登录、装备、角色和宠物页沿用同一组件系统。

## 10.5 协作美术规范（V1.3）

后续建模、绘制和特效应遵循以下统一特征，确保新增内容与现有画风相似：

- **总体方向**：二维 Canvas 卡通奇幻风，轮廓圆润、形体略夸张、颜色高对比；不追求写实纹理，优先保证 320×568 手机尺寸下的轮廓识别。
- **轮廓与层次**：主体使用深青灰粗描边（约为模型半径的 8%~12%），主体内部使用一到两级纵向渐变；地面统一绘制低透明度椭圆阴影，表现角色与怪物落地关系。
- **角色**：福瑞角色采用柔和脸部曲线、尖耳、双色脸颊、奶油色尾尖、渐变虹膜和少量衣物结构线；待机动画只做低幅度摇尾、呼吸、眨眼、抖耳、围巾摆动，脚底保持接地。
- **怪物**：模型必须同时表达“身体轮廓 + 职能特征 + 面部朝向”。普通怪使用耳朵、眼睛和身体姿态区分；快速怪强调瘦长与腿部动势；远程怪配法杖/投射物；自爆怪配炸弹体与引线；猎人配尖耳和弧形武器；治疗怪配十字标记；护盾怪配独立盾牌；召唤怪配兜帽与能量环；精英配护甲和棱角；Boss 配冠饰、放大比例和种类专属色。树怪保留树干、根系、树冠、发光眼和枝臂。
- **色彩语义**：己方以青绿、暖金、浅蓝为主；敌人按职能使用红/橙（攻击与爆炸）、紫（远程/召唤）、绿（治疗）、蓝（护盾/冰冻）；同色不可同时表示相反危险等级。
- **受击与状态**：受击使用短于 0.1 秒的浅色闪白；燃烧用橙红火舌和少量黑烟；冰冻用半透明多边形冰块、裂纹和霜圈；护盾用蓝色环；Boss 狂暴用红色外环。特效先表达方向和危险范围，再添加发光、粒子和震屏。
- **特效预算**：单个命中特效应在 0.2~0.45 秒内结束；粒子采用少量高亮点和渐隐拖尾，避免持续大面积半透明叠加；精简环境特效和 `prefers-reduced-motion` 必须能关闭漂浮、震屏和非必要粒子。
- **新增内容流程**：先用 Canvas 几何图形完成轮廓与命中尺寸，再补渐变、纹理和特效；每个新增敌人必须提供静态轮廓、移动姿态、受击帧、死亡反馈、危险技能预警五项；绘制函数不得修改实体坐标、伤害和碰撞参数。
- **验收尺寸**：至少在 390×844、320×568、900×450 检查轮廓、血条、技能预警和特效遮挡；新增内容需补入 `tests/visual-smoke.js`，并保持浏览器控制台 error / warn 为 0。
