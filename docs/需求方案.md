# 《福瑞快打》需求方案（V0.9 · 与当前实现同步）

## 1. 项目概述

| 项目 | 内容 |
|---|---|
| 名称 | 福瑞快打 |
| 游戏类型 | 竖屏休闲动作闯关（自动战斗 + 大地图探索 + Roguelike 升级 + Boss 战） |
| 平台 | H5（纯前端 Canvas，可打包为 Windows exe） |
| 当前模式 | **无尽模式**（生存波次制，每 10 波 Boss，阵亡结算） |
| 局外养成 | 金币解锁武器/装备/宠物，用户存档落盘到本地 JSON 文件 |

**核心循环**：主菜单配装 → 进图打怪 → 掉经验升级 → 每 10 波 Boss → 击败 Boss 选 2 项奖励 + 世界成长（新怪物 / 出怪量 / 经验加成 / 场景植物）→ 阵亡结算 → 赚金币解锁更多内容。

- **登录系统**：用户名 + 密码。点击「注册」进入注册模式（需输入用户名、密码、确认密码并校验），全部通过后才创建账号并进入；用户名唯一；多账号数据隔离。
- **打包**：已配置 Electron（`package.json` + `electron/main.js` + `build/icon.png`），本机运行 `npm install && npm run dist` 生成 Windows exe。

## 2. 主菜单（局外养成）

**开场动画**：首次进入主菜单（每次页面加载一次，约 2.6 秒）播放全屏标题动画（渐变标题 + 光环扩散 + 光带扫过），点击任意处可跳过。

**主页（独立初始界面）**：整屏单屏布局（无需滚动），顶部一行是左侧用户名、右侧「金币显示 + 设置图标按钮」（金币在设置左侧，点击金币查看获取方式），中部是渐变游戏标题与**角色悬浮展示区**（角色轻微上下浮动，点击进入角色个性化），下方是大号「开始游戏」按钮与最佳波次，底部为 3 个功能入口。

| 入口 | 位置 | 内容 |
|---|---|---|
| 金币 | 顶部（点金币徽章） | 当前金币 + 获取方式（小怪 +1 · 精英 +5 · Boss +50） |
| 设置 | 顶部（齿轮图标） | 音效开关、显示方向（竖屏/横屏）、帧率上限、重置进度、退出登录 |
| 角色 | 点角色展示区 | 角色个性化：毛色 6 · 服装 6 · 头饰 5 · 眼睛 4 · 体型 3，**改动实时预览** |
| 装备 | 底部 | 武器（步枪/散弹/机枪/狙击枪）、护甲·饰品（无/皮甲/力量护符/血珠）、物品（无/回血宝珠）的解锁与装备 |
| 宠物 | 底部 | 宠物养成：宠物（无/龙蛋/火焰精灵）的解锁与装备 |
| 背包 | 底部 | 已拥有物品一览 |

子页面均带「返回」按钮回到主页。

**角色外观**：首页预览与局内角色共用同一套外观数据（`meta.character`），已保存在账号存档中。

**解锁与装备**
- 金币在结算时累加并保存。
- 用金币解锁新武器/装备/宠物，解锁后自动装备，可随时切换。

| 类别 | 选项 | 解锁价 |
|---|---|---|
| 武器 | 步枪（默认）/ 散弹 / 机枪 / 狙击枪 | 散弹 200 · 机枪 300 · 狙击枪 400 |
| 装备 | 无（默认）/ 皮甲 / 力量护符 / 血珠 | 皮甲 100 · 护符 150 · 血珠 260 |
| 物品 | 无（默认）/ 回血宝珠 | 回血宝珠 200 |
| 宠物 | 无（默认）/ 龙蛋 / 火焰精灵 | 龙蛋 150 · 火焰精灵 250 |

| 新装备 / 物品 | 效果 |
|---|---|
| 狙击枪（武器） | 单发 46 伤害、2s/发、自带穿透 1、细长紫色曳光弹道 |
| 血珠（装备） | **造成伤害时有 5% 概率回复该次伤害的 5%**（触发型回血，独立于吸血） |
| 回血宝珠（物品） | **每秒回复 2 点队伍血池**（走 `stats.regen`，不受乘区影响） |

> 「物品」是本次新增的第三个局外槽位（武器 / 装备 / 物品 / 宠物），与装备互不冲突，可同时佩戴。

## 3. 伤害模型（四种类型）

| 伤害类型 | 字段 | 归属 |
|---|---|---|
| 子弹伤害 | `bulletDamage` | 武器（步枪/散弹/机枪/狙击枪） |
| 元素伤害 | `elementalDamage` | 元素类：火球、雷电、冰刺、燃烧（火焰） |
| 召唤物伤害 | `summonDamage` | 召唤物：镰刀、飞剑 |
| 宠物伤害 | `petDamage` | 龙蛋（其点燃仍属元素伤害） |

> **元素类已与召唤物彻底分开**：火球 / 雷电 / 冰刺归类为「元素类」，只吃**元素伤害**加成，**不再享受任何召唤物加成**；镰刀 / 飞剑归「召唤物」，只吃召唤物伤害加成。两类都走「升级卡加算 + 进化独立乘区」的同一套算法。

**乘区规则（参考主流做法：PoE 的「增加 / 更多」、Vampire Survivors 的同类加算）**

```
最终伤害 = 基础值 × (1 + 同类加成之和) × 独立乘区
```

- **同类百分比一律「加算」**：所有"+30% 子弹伤害""-30% 元素伤害"都塞进同一加算区，最后只乘一次。避免同类加成反复相乘——那会让"一直选元素"这种路线指数爆炸（元素 ×191、子弹 ×0.002 直接变成 1 点伤害）。
- **只有独立来源才进乘算区**：局外装备（力量护符 ×1.15）、进化终极形态（如烈焰风暴 ×1.3）。
- **减益进同一加算区，并留下限**：`DMG_FLOOR = 0.3`，任何一路伤害最低保留 30%，不会被扣到 0。
- **转换卡限次**：子弹→元素的「元素法师」每局最多 2 次（同类加成相加后本身也不会失控）。
- **新增乘区一律遵守同一规范**：新加的任何数值加成（如「嗜血」的易伤 / 吸血）都要进自己的「同类加算区」，同类之间相加、只乘一次，并遵守 30% 下限——不得新增连乘区。
  - **易伤**（`stats.vuln`，同类加算）：敌人受到的伤害 = 原伤害 ×(1 + Σ易伤)，在命中结算处只乘一次。
  - **吸血**（`stats.lifesteal`，同类加算）：按实际造成伤害的百分比回复队伍血池；镰刀的 10% 吸血属「进化 · 死神镰刀」的专属效果。
  - **回血**（`stats.regen`，固定值）：回血宝珠提供 +2/s 的队伍血池回复，不参与百分比乘区。
  - **触发型回血**（`stats.bloodOrb`，概率）：血珠在造成伤害时按 5% 概率回复该次伤害的 5%。
- 召唤物 / 宠物伤害同理：升级卡进加算区（`dmgAdd`），进化进独立乘区（`dmgMore`），最终折算成 `dmgMul` 参与计算。

| 举例（元素法师 ×2 + 强力子弹 ×3 + Boss 元素 ×2） | 旧（连乘） | 现（加算） |
|---|---|---|
| 子弹倍率 | ×0.269 | ×0.3（触下限） |
| 元素倍率 | ×5.76 | ×3.4 |

| 极限对照（元素法师 ×6 + Boss 元素 ×6） | 旧（连乘） | 现（加算） |
|---|---|---|
| 子弹倍率 | ×0.0018（子弹彻底报废） | ≥×0.3 |
| 元素倍率 | ×191 | ×6.4 |

## 4. 战斗系统

**小兵（共享血池）**：初始 1 名，站桩跟随队形。

- **血条共享**：所有小兵共用一条队伍血池 `squadHp`，上限 = 小兵数 × 单个小兵血量（`小兵初始生命 100 × 生命上限加成`）。
- 所有小兵头顶显示的都是**同一条队伍血条**；受到的伤害统一结算进血池，**不会单独死亡**。
- **掉一格（= 一个小兵的血量）就消失一个小人**：血池降到不足一个小兵的血量时，对应数量的小兵当场消失（带红色粒子），血池上限同步下调；血池见底则全部消失、判定失败。
- 受伤免疫（护盾 / 免疫时长 / 闪避）统一作用于队伍：受击后整队进入免疫，而不是单个小兵。
- 范围伤害（自爆怪爆炸、Boss 冲刺）对共享血池**只结算一次**，不会因为一次打到多名小兵而翻倍。

**武器（局外携带，攻击间隔作为 CD）**

| 武器 | 机制 | 局内升级 |
|---|---|---|
| 步枪 | 单发直射 | 射速 +20% / 特殊（穿透） |
| 散弹 | 扇形多发弹丸 | 射速 +20% / 特殊（击杀分裂） |
| 机枪 | 高速连射 | 射速 +20% / 特殊（狂暴，全局仅一次） |
| 狙击枪 | **高额单发（46 伤害）、射速很慢（2s/发）、自带穿透 1、弹道为细长紫色曳光** | 射速 +20% / 穿透 +1（最多 4）/ 射程 +20% / 特殊（蓄力弹：子弹加成 +30%、射速 -25%，仅一次） |

> 武器的**伤害成长只走「强力子弹」**（子弹伤害 +30% / 击退 +10%）与新增的特殊卡，不再有「武器伤害 +30%」这类升级卡。

**元素类（局内获得，走元素伤害）**

| 元素 | 机制 | 局内升级 |
|---|---|---|
| 火球 | 命中敌人时召唤火球打最近敌人，带 CD | 伤害 / 冷却 / 爆炸范围 / 点燃 / 火焰持续时间 / 数量 / 击杀爆炸 |
| 雷电 | 命中敌人时随机劈一名敌人，带 CD | 伤害 / 冷却 / 次数 / 链式 |
| 冰刺 | 定期在**附近敌人脚下刺出冰柱**，造成元素伤害并附加**霜冻减速**（基础 55% 移速 / 2.2s） | 伤害 / 冷却 / 目标 +1 / 霜冻更强 / 霜冻 +0.6s / 范围 +20% / **冰冻**（20% 概率冻住，可再 +15% 概率、+0.4s 时长，最多 60%） |

**召唤物（局内获得，走召唤物伤害）**

| 召唤物 | 机制 | 局内升级 |
|---|---|---|
| 镰刀 | 环绕自身旋转，接触伤害 | 数量 / 飞行速度 / 伤害 / 变大 / 阻挡子弹 / 击退 |
| 飞剑 | **主动飞向视野范围内（基础 300）的敌人**，接触造成伤害；飞越障碍物 | 伤害 / 冷却 / 数量 / 索敌范围 +20% / 飞行速度 +20% / 穿透（最多 2） |

**镰刀特性**：阻挡子弹默认 10%（+15%/+20%，最多 45%）；击退平滑位移并带 1 秒抗性；**10% 吸血为「进化 · 死神镰刀」的专属效果**（未进化不吸血）。

**雷击表现**：预生成 7 段锯齿状闪电（外发光 + 中层 + 白色内核三层描边，电弧轻微闪动）+ 1 条分叉；落点有白色闪光与扩散的地面冲击环，整体 0.26s 内淡出。

**霜冻 / 冰冻表现**：霜冻中的敌人被寒气光晕包裹，脚下有霜圈，周围有 5 颗旋转的小冰晶（剩余时间越短越淡），移动速度按霜冻倍率下降；触发冰冻时整个人被封进一块多边形冰块（冰面高光 + 裂纹），期间完全无法移动。Boss 的霜冻照旧按「元素效果减半」处理（时长与减速幅度都减半）。

**宠物（龙蛋 / 火焰精灵，唯一）**：悬浮角色右上方轻微晃动并发射子弹；龙蛋点燃 1s，火焰精灵快速连射并点燃 0.8s。

**点燃表现（身上着火）**：被点燃的敌人会被动态火焰包裹——脚下/身上的橙色光晕 + 5 条从身体四周升起的火舌（橙红→亮黄渐变、左右摆动、高度跳动，用叠加发光渲染）+ 上升火星；燃烧时间越短火焰越淡，熄灭前自然收尾；同时按燃烧 DPS 持续掉血。

**敌人**

| 类型 | 特点 |
|---|---|
| grunt | 红色近战 |
| fast | 橙色快速 |
| ranged | 粉色远程，射程限制 300 |
| elite | 紫色精英，每 5 波 1 个；**被动护盾**（= 60% 血量，破盾 3 秒后按 10/秒恢复） |
| boss | 每 10 波 1 个，见「Boss 战」 |

**特殊敌人**（击败第 1 个 Boss 后开始逐步加入随机卡池）

| 类型 | 解锁条件 | 特点 |
|---|---|---|
| bomber 自爆怪 | 击败 1 个 Boss | 高速贴身，接触或被打死时范围爆炸伤害小兵 |
| hunter 追踪兵 | 击败 2 个 Boss | 保持距离发射**追踪弹**（缓慢转向最近小兵） |
| healer 治疗兵 | 击败 3 个 Boss | 维持中距离，每 2.4s 治疗附近最多 3 名敌人 |
| shielder 护盾兵 | 击败 4 个 Boss | 自带 50% 血量护盾，每 4s 给周围最多 4 名敌人套小护盾（上限该敌人 40% 血量） |
| summoner 召唤兵 | 击败 5 个 Boss | 远离小兵，每 5s 召唤 1~2 名小怪，靠近则后撤 |

**可破坏物与掩体**（每局随机 18 个，不挡出生点）

| 类型 | 特点 | 外观 |
|---|---|---|
| 木桶 | 40 血，破坏后 +3 金币 + 8 经验 | 棕色木桶：桶盖 + 两道灰色金属箍 |
| 箱子 | 60 血，破坏后 +5 金币 + 12 经验 | 木板箱：外框木条 + 交叉斜条 + 四角铁钉 |
| 石柱 | 不可破坏，**挡下双方子弹**（可作为掩体） | 石柱：柱头 + 竖向凹槽柱身 + 底座（带受光面） |

> 三者均带地面阴影。注意不要画成同心圆——那样会被误认成金币。
> **三者都会阻挡玩家 / 小兵 / 敌人的移动**（按圆形碰撞把单位推出，可在战斗中当掩体）；木桶与箱子被摧毁后立刻不再阻挡，石柱永久阻挡。

**场景植物（世界异变）**：第一次击败 Boss 后开始在地图上长出树木与藤蔓，并在之后每次击败 Boss 时继续补充（树木上限 36、藤蔓上限 20）。约 6 成生成在玩家视野内的环带（树木距玩家 ≥150、藤蔓 ≥220），便于看到生长过程。

> 表现：树木与藤蔓为矢量绘制——树木＝地面阴影 + 根系 + 锥形树干（含高光）+ 分层树冠（暗底 / 主体 / 受光面，随风轻摆，苏醒中逐渐枯黄并透出红光）；藤蔓＝地面阴影 + 藤丛底座 + 一圈带叶片的藤须。生长过程为「从根部放大」的破土动画，未长成时按 2% 缩放隐藏。

| 植物 | 机制 |
|---|---|
| 树木 | **破土生长 2.6s**（从根部向上放大的动画，smoothstep 曲线，全程都在长）；生长期间不挡子弹、不挡路、不计靠近时间。长成后算作**实体**（**挡下子弹且阻挡玩家与小怪通行**）但**无敌、无血条**（打不掉）；小兵在其附近累计停留 3.5s（外圈显示苏醒进度环，离开则进度回落）会**苏醒为树怪**；树怪 180 血（较厚）、近战 18 伤害，可正常击杀并获得 90 经验 + 6 金币 |
| 树怪造型 | 以树木为基础：根系 + 锥形树干 + 分层树冠，额外加**发光红眼（呼吸明暗）+ 锯齿嘴 + 双臂（带三根手指小枝）+ 双腿（交替摆动）**，并跟随小兵方向转头；血条抬到树冠上方 |
| 藤蔓 | **长出动画 1s**（从小长到大的破土动画），期间不触发缠绕；长成后存在 25~40s 自行消失；玩家进入 110 范围触发**前摇 0.9s**（藤须朝玩家方向伸出、抓取范围红圈由小变大，可跑出躲避）；命中则**缠住玩家 1.8s**（无法移动），随后藤蔓消耗消失；被躲开则进入 2.5s 冷却 |

> 生长动画在 Boss 奖励面板关闭、游戏恢复时继续播放（面板打开期间世界处于暂停）。

## 5. Boss 战

- 每 10 波 1 个 Boss，血量/颜色/技能按种类轮换（10 波冲锋 → 20 波弹幕 → 30 波召唤 → 40 波分裂 → 循环）。
- 通用行为：追击 + 接触伤害 + 周期性弹幕，出场与狂暴均有居中横幅提示。
- **控制抗性**：Boss **免疫击退**（子弹击退与镰刀击退均无效）；**元素效果减半**——燃烧强度（DPS）与燃烧持续时间都 ×0.5。
- **冲刺读条（冲锋者）**：蓄力期间地面显示完整危险区——红色底色 + **由内向外推进的蓄力填充**（黄色→橙红渐变）+ 两侧流动虚线 + 终点箭头；Boss 脚下有随进度收紧的蓄力环；Boss 头顶显示**渐变进度条 + 文字提示**，进度 > 72% 时切到「即将冲刺！」并整体变红、高频闪烁；冲刺过程中显示拖影与冲击环。

| 种类 | 血量 | 特点 |
|---|---|---|

## 6. 升级系统（普通升级）

- 经验条满触发；默认 3 选项，可「升级选项 +1」至最多 6。
- 按权重随机；不含武器解锁。

| 类别 | 选项 |
|---|---|
| 生存/功能 | 移速 · 生命上限 · 医疗包 · 增援+1(子弹加成-30%) · 拾取范围 · 护盾+20 · 受伤免疫 · 升级选项+1 |
| 特殊 | 强力子弹(子弹+30%击退+10%) · 元素法师(子弹-30%元素+20%，同类相加、每局最多 2 次) · 闪避+20% · **嗜血(易伤 +20% / 吸血 +1%)** |
| 武器 | 射速 +20% / 特殊（步枪穿透·散弹分裂·机枪狂暴·狙击枪穿透/射程/蓄力弹） |
| 元素：火球 | 解锁 / 伤害 / 冷却 / 爆炸范围 / 点燃 / 火焰持续时间 / 数量 / 击杀爆炸 |
| 元素：雷电 | 解锁 / 伤害 / 冷却 / 次数 / 链式 |
| 元素：冰刺 | 解锁 / 伤害 / 冷却 / 目标 +1 / 霜冻更强 / 霜冻 +0.6s / 范围 +20% / 冰冻 → 冰冻概率 / 冰冻时长 |
| 召唤物：镰刀 | 解锁 / 数量 / 飞行速度 / 伤害 / 变大 / 阻挡子弹 / 击退 |
| 召唤物：飞剑 | 解锁 / 伤害 / 冷却 / 数量 / 索敌范围 / 飞行速度 / 穿透 |
| 宠物 | 龙蛋/火焰精灵 伤害 / 攻速 |
| 主动技能 | 时缓解锁 · 时缓时长/冷却 |

**嗜血**：敌人受到的伤害 +20%（**易伤**，进同类加算区，与其它易伤来源相加后只乘一次）；同时每段造成的伤害额外回复其 **1%** 的队伍血池。可重复选，线性叠加（+20% / +40% / …），不会指数爆炸。

**升级重掷**：每局 3 次（击败 Boss +1），在升级面板点击「重掷」重抽当前 3 项；用尽后按钮隐藏。

**进化（终极形态）**：需要**本路线强化次数达标**（默认 3 次）+ 专属前置满足，之后才会以**低权重（0.8，非保底）**随机出现在卡池里；卡面带金色「进化」标签，每项每局限一次。

《进化获取难度》：进化不再「满足前置就必出」——除了前置条件，还必须在本路线累计拿到 3 张强化卡（`routePicks`），且出现权重只有 0.8（普通卡为 1.0）。实测每次升级抽到某条已达标进化的概率约 13%，需要多次升级才有机会遇到。

| 进化 | 路线（需 3 次强化） | 前置 | 效果 |
|---|---|---|---|
| 穿甲连射 | 步枪 | 步枪穿透 3 级 | 穿透 +3、伤害 +50%、弹速 +25% |
| 霰弹风暴 | 散弹 | 散弹分裂 30% | 击杀分裂 2 → 4 枚、伤害 +30% |
| 死亡射线 | 机枪 | 机枪狂暴 | 攻速 +80%、穿透 +2 |
| 湮灭狙击 | 狙击枪 | 狙击枪穿透 3 级 | 穿透 +3、伤害 +70%、弹速 +30% |
| 烈焰风暴 | 火球 | 火球点燃 + 击杀爆炸 | 数量 +2、爆炸范围 +50%、点燃 +1s、伤害 +30% |
| 苍穹雷暴 | 雷电 | 雷电链式 3 级 | 次数 +2、链式上限 +2、伤害 +30% |
| 绝对零度 | 冰刺 | 已解锁冰冻 | 目标 +2、范围 +40%、霜冻更强、冰冻概率 +25% |
| 死神镰刀 | 镰刀 | 镰刀击退 + 变大 | 数量 +2、伤害 +40%、阻挡子弹 45%、**造成伤害的 10% 吸血** |
| 万剑归宗 | 飞剑 | 飞剑穿透 1 级 | 数量 +2、穿透 +2、伤害 +40% |

> 步枪原进化名「穿甲狙击」已改名为**「穿甲连射」**，避免与新武器「狙击枪」以及其进化「湮灭狙击」重名。

**前置条件（卡池不会出现无前置的后续选项）**

- 局内能力派系（元素：火球 / 雷电 / 冰刺；召唤物：镰刀 / 飞剑）的强化卡，只有在已获得该能力后才进入卡池。
- 火球：先「点燃」才会出现「火焰持续时间」；先「击杀爆炸」才会出现「击杀爆炸范围 / 伤害」。
- 冰刺：先「冰冻」才会出现「冰冻概率 / 冰冻时长」。
- 镰刀：阻挡子弹按 10% → +15% → +20%（最高 45%）递进，拿到上一级才出现下一级。
- 元素法师、Boss 的元素类奖励（元素伤害 / 元素触发频率 / 子弹+50%元素清零）只有存在元素伤害来源（火球 / 雷电 / 冰刺 / 带点燃的宠物）时才出现。
- 武器特殊卡（步枪穿透 / 散弹分裂 / 机枪狂暴 / 狙击枪穿透·射程·蓄力弹）只在携带对应武器时出现。
- 机枪狂暴：**全局仅出现一次**，且权重极低（0.3）；效果为射速 +50%、移速 -15%、伤害 -30%。狙击枪蓄力弹同样仅一次。
- 已达上限的卡（闪避 60%、受伤免疫 1.5s、步枪穿透 3、狙击枪穿透 4、散弹分裂 30%、闪电链式 3、冰冻 60%、飞剑穿透 2、升级选项 6）不再出现。

**子弹穿透**：穿透次数在命中不同敌人时逐次消耗，同一发子弹不会重复命中同一敌人；穿透耗尽后子弹在命中时消失。

## 9. 数值与平衡

- 升级节奏：初始经验需求 **15**，逐级 `×1.25 + 5`（15 → 23 → 33 → 46 → 62 → 82…）。
- 世界成长（每击败 1 个 Boss）：**经验获取 +20%**、**出怪量 +12%**（同时生效于每波怪量与出怪间隔，间隔加速上限 1.6 倍），并同步刷新场景植物。
- **第一个 Boss 之后，小怪与出怪开始随波次动态成长**（Boss 自身血量仍走「动态难度」）：
  - 小怪血量倍率 `enemyHpScale()`：第一个 Boss 前 = 1；之后 = `1 + 0.05 × (波次 - 10) + 0.25 × (Boss 数 - 1)`。
  - 出怪倍率 `spawnScale()`：`1 + 0.12 × Boss 数`，且击败过 Boss 后额外 **+0.10 基础值并随波次增长**（`+0.05 × max(0, 波次 - 10)`），同时加快出怪间隔。
- 雷电单次伤害 22（元素）。
- 增援 +1 附带子弹伤害 -30%。
- 动态难度：每击败一个 Boss 难度 +0.25（上限 3 倍），影响敌人血量/伤害/速度。
- 受伤免疫上限 1.5s；镰刀单敌受击冷却 0.25s；闪避上限 60%。

## 10.1 局内 HUD 与设置（已实现）

- 局内 HUD：顶部居中显示**对局时长**（mm:ss），左上显示波次/小兵/Lv，右上显示击杀/金币/护盾。

- 顶部居中提供**暂停按钮**，打开暂停面板，包含：
  - 继续游戏 / **新游戏**（放弃当前进度，从第 1 波重开）/ 返回主菜单
  - 对局摘要（对局时长 · 波次 · 击杀；击败过 Boss 后追加 经验加成 / 出怪加成）
  - 显示方向：**竖屏 / 横屏**（逻辑分辨率按真实屏幕比例自动推导）
  - 帧率上限：30 / 60 / 120 / 不限
- **返回主菜单会保留本局进度**：整局状态（波次 / 击杀 / 等级 / 经验 / 已获升级 / 小兵 / 召唤物 / 宠物 / 场景植物 / Boss 进度 / 倒计时等）会快照进账号存档（`meta.run`，约 12KB），下次点主菜单的「开始游戏」会**直接回到这局的暂停 / 设置界面**，可继续或点「新游戏」重开。

- 显示方向与帧率同样可在主菜单「设置」页调整，并保存到账号存档。
- 暂停按钮只在真正对局中显示（升级、Boss 奖励面板打开时自动隐藏）。

## 10.2 屏幕适配（已实现）

- **逻辑分辨率跟随屏幕比例**：竖屏以宽 450 为基准、横屏以高 450 为基准，另一维按真实屏幕比例换算。
  - 竖屏允许区间 16:9 ~ 22:9（450×800 ~ 450×1050），横屏为其倒数（800×450 ~ 1050×450），覆盖主流手机；
  - 手机屏内**满屏显示、不留黑边、不拉伸**；超出区间（如桌面宽屏开竖屏）时等比留边居中。
- **高清渲染**：canvas 后备缓冲按设备像素比（上限 2 倍）放大，避免高清屏发虚。
- **无滚动条**：`html/body` 禁止滚动，菜单/面板保留滚动能力但隐藏滚动条；首页与暂停面板在竖屏、横屏下均单屏放得下。
- 窗口尺寸或手机方向变化时自动重新适配（含防抖）。
