# 更新日志

> ## 维护约定（改代码前先读）
>
> 1. **每次「较大改动」必须在本文件顶部追加一节，并同步更新 `docs/需求方案.md` 的对应章节**，两者缺一不可。
> 2. 什么算「较大改动」：新增/重做机制、新卡牌或新进化、新系统、成批数值调整、表现大改。
>    只调一两个数字或修错别字，可并入当天已有的一节，不必新开版本。
> 3. 每节写法：`## vX.Y · YYYY-MM-DD —— 一句话主题`，下面按 **新增 / 调整 / 修复** 列要点；
>    每条一句话说清「改了什么 + 为什么 / 效果」，涉及数值的直接写清 旧 → 新。
> 4. 版本号：机制重做、新系统、成批数值调整 → `+0.1`；纯数值微调 → 可用 `vX.Y.Z`。
>    `docs/需求方案.md` 的标题版本号要与本文件最新一节保持一致。
> 5. 提交前自查：`需求方案.md` 是否与本文件一致？本次改动有没有漏记？
>    数值尽量先在浏览器测试台实测再写进文档，不要写估算值。

## v1.8 · 2026-09-19 —— 排行榜前三名装饰

### 新增

- 排行榜**榜首加皇冠**：第 1 名玩家名前渲染一枚内联 SVG 皇冠（`boardCrown()` + 常量 `CROWN_SVG`），该行同时改为金色描边 + 左起渐变高亮（`color-mix` 按主题色算透明度）。
- 第 2、3 名的名次数字分别用银灰 `#c3cfd4` 与铜橙 `#d79a63`，第 4 名起保持原有暖金，一眼能分出金银铜三档。
- 皇冠填充取主题变量 `--gold`，因此会跟随五种界面主题变色（如霓虹街机为粉紫）；用内联 SVG 而非 emoji，避免各平台字体差异。描边沿用协作美术规范里的深色粗描边。

### 调整

- `.board-user` 由纯文本改为 flex 容器，玩家名包进新的 `.board-name`：皇冠用 `flex: none` 固定在名字左侧，名字过长时只截断名字本身、皇冠不会被一起压掉。

### 验证

- `node --check js/game.js` 通过。
- 浏览器实测（本地 8080，四种榜单数据）：第 1 名名前有完整 15×12px 皇冠，几何上与名字、行中线对齐，无裁切/错位；皇冠与名字的 x 坐标分别为 371.1 / 391.1，确认在名字左侧。
- 第 1 名整行 `border-color: rgb(242,204,131)`（= `--gold`）且背景为左起渐变；第 2、3、4 名名次分别为银灰 `rgb(195,207,212)`、铜橙 `rgb(215,154,99)`、暖金 `rgb(242,204,131)`。
- 主题跟随：五个主题下逐一切换实测，行底分别为 `rgb(20,44,48)` 森林 / `rgb(246,236,217)` 暖纸 / `rgb(35,35,35)` 原始 / `rgb(23,20,43)` 霓虹 / `rgb(17,30,59)` 星夜，均等于各自 `--surface`；霓虹街机下皇冠填充实测 `rgb(255,142,203)`，描边与渐变同步变粉紫。
- 名次色对比度（WCAG 相对亮度）——**金1 / 银2 / 铜3 / 金4**：暮色森林 6.93 / 11.57 / 10.28 / 9.59；暖纸手绘 4.72 / 4.91 / 5.87 / 5.37；原始精简 7.86 / 13.82 / 12.34 / 11.14；霓虹街机 6.95 / 14.14 / 12.58 / 8.52；深海星夜 7.78 / 12.97 / 11.50 / 10.80 —— **四个名次档在五个主题下全部 ≥ 4.5:1**。
- 最后这组数字由脚本按 CSS 取值算出（行底按 `linear-gradient` 左端金色 15% 叠在行底上合成）。算法与浏览器实测做过校准：用同一模型算「纯 `--gold` vs 榜首行底」，五个主题得 6.72 / 4.34 / 7.56 / 6.49 / 7.54，与浏览器实测的 6.90 / 4.40 / 7.76 / 6.28 / 7.57 误差 ≤ 3.3%。
- 长名截断时皇冠保持 15px 不动（`.board-crown` 不收缩），只截断 `.board-name`。
- 排行榜页、主菜单、设置页控制台均无 error / warning。

### 修复

- 修复榜单**行底不跟随主题**的问题：`.board-row` 的行底与 `.board-user` 的文字色原先硬编码（`#152f34d9` / `#e7eddf`），导致暖纸手绘这类浅色主题下皇冠只有约 2.2:1。现改为行底 `color-mix(in srgb, var(--surface) 92%, transparent)`、玩家名 `var(--ink)`（与 `.tab` / `.card` 同一范式），选中行 `color-mix(in srgb, var(--mint) 10%, var(--surface))`。
- 修复**银/铜名次色在浅色主题下不可读**：行底改为跟随主题后，写死的银 `#c3cfd4` 与铜 `#d79a63` 落在暖纸手绘的浅底上只剩 1.36:1 / 2.06:1。现改为 `color-mix(in srgb, #c3cfd4 30%, var(--ink))` 与 `color-mix(in srgb, #d79a63 30%, var(--ink))`——深色主题下偏亮、浅色主题下偏暗。
- 修复**榜首名次色在暖纸手绘下差一点点**：冠军数字落在榜首行金色渐变的左端，局部底色被金色抬亮，纯 `--gold` 只有 4.40:1。现改为 `color-mix(in srgb, var(--gold) 88%, var(--ink))`，升到 4.72:1；第 4 名起落在纯行底上，保持 `--gold` 不变。

### 已知限制

- 舞台宽度过窄时（视口高 < 约 440px，舞台宽 < 约 250px）榜单网格 `34px 1fr 72px` 会先把名字列压到几乎没有空间，榜首名字基本看不见；该尺寸低于协作美术规范的最小验收尺寸 320×568。

## v1.7 · 2026-09-18 —— 会话令牌与竞技防作弊 + 测试模式升级为开发者模式

### 新增

- 新增**会话令牌**：登录 / 注册时下发无状态签名串（`payload.HMAC-SHA256`，含用户名、密码版本与 30 天有效期），前端存 `localStorage.fury_token`。存档写入、成绩提交、读账号、删号都必须带令牌，且**只能操作自己的账号**（读别人的返回 403）。
- 新增 `api/_auth.js`：令牌签发与校验，`Vercel` 不会把 `api/` 下以 `_` 开头的文件暴露成接口。
- 排行榜提交增加**服务端合理性校验**：需令牌、身份取自令牌（请求体里的用户名无效），并要求同时上报本局对局时长；`波次 ≤ 时长 ÷ 2 + 30`、时长上限 12 小时、波次上限 5000，超出直接拒绝。
- 新增 `supabase/migrations/0004_submit_score_guard.sql`：`submit_score` 改为三参数 `plpgsql`，把只增不减与合理性校验放在同一条语句里，校验失败抛出 `wave_too_fast` / `wave_out_of_range` / `duration_out_of_range`。
- 「隐藏测试模式」升级为**开发者模式**：设置页连按音效 10 次后弹出**密码验证**，密码正确才进入；密码不在仓库与文档中出现，代码里只存它的 SHA-256。
- 开发者面板新增调试能力：清空未结束对局、**导出 / 导入存档 JSON**（导入会覆盖并保存，非法 JSON 给出原因）、退出开发者模式，并在面板顶部显示账号 · 存档通道 · 存档体积 · 是否有未结束对局。
- 新增**存档本机镜像**：每次存档先写 `localStorage.fury_meta_<账号>`，再同步后端；失败按 0.8s / 1.6s 退避重试两次，仍失败时首页提示「存档暂未同步到云端，已存在本机，联网后自动重试」。
- 每次存档写入 `meta.savedAt`；下次登录若本机镜像比云端新，会询问是否用本机这份覆盖云端。

### 调整

- 注册改用 `ignore-duplicates` 原子新建（只能新建、不能覆盖）；改密只更新密码两列**不再顺带写 `meta`**，避免旧客户端拿陈旧存档覆盖新进度。
- `GET /api/users?username=` 由「谁都能读」改为「需令牌读自己」；令牌校验顺带比对密码版本，**改密后旧令牌立即失效**。
- 开发者模式的面板与设置项 ID 从 `test-*` 统一改为 `dev-*`，账号字段由 `meta.testMode` 改为 `meta.devMode`。
- `normalizeMeta` 补齐 `coins` / `bestWave` / `run` / `devMode` 的默认值：缺字段的存档（含导入存档）不再出现 `bestWave` 为 `undefined` 导致记录不再更新。
- Home 页新增存档未同步提示条；主页底部导航四列布局。

### 修复

- 修复「任何人只要拿到用户名就能改写或删除别人账号存档」的问题（此前 PATCH / DELETE 无鉴权）。
- 修复在控制台改写 `localStorage.fury_current_user` 即可冒充他人登录的问题。
- 修复返回首页的进度快照在网络抖动时静默丢失、且没有本地兜底的问题。
- 修复**删号后榜单仍留孤儿记录**的问题：`DELETE /api/users` 现在顺带清掉 `scores` 里该账号的行（旧行为是账号没了、榜上名字还在）。

### 验证

- `node --check` 通过（`js/game.js` / `server.js` / `api/users.js` / `api/leaderboard.js` / `api/_auth.js`）。
- 本地接口 41 项断言全通过：无令牌读写删一律 401、拿自己的令牌读写他人 403、伪造签名与乱码令牌 401、无令牌提交成绩 401、波次远超时长与略超时长均 400、合法成绩 200、更低波次不覆盖、请求体冒名提交会归到令牌本人、注册与改密返回新令牌、改密后旧令牌 401 且旧密码登录失败、改密不清空存档、令牌可删自己的号。

## v1.6 · 2026-09-18 —— 最久波次排行榜 + 密码哈希与服务端校验

### 新增

- 新增**最久波次排行榜**：主菜单 → 排行榜，按账号最久波次倒序，每位玩家一行、当前账号高亮。阵亡结算时自动上报 `meta.bestWave`。
- 新增 `api/leaderboard.js`（GET 取榜 / POST 提交）、Supabase `scores` 表与 `submit_score` 数据库函数：在一条语句里取较大值，波次更小则整行不变，多人同时提交不会互相覆盖。
- 实时更新三级保障：首屏走接口快照 → 前端用原生 `WebSocket` 直连 Supabase Realtime 订阅 `scores` 表的 `postgres_changes`（秒级刷新，未引入 `supabase-js`，保持零运行时依赖）→ 订阅不可用 / 断开 / 8 秒无应答时自动降级为每 8 秒轮询兜底。
- 新增登录接口 `POST /api/users { action:'login' }`：**密码比对改在服务端完成**，明文口令只在 HTTPS 上传输一次，账号数据返回时不含密码。
- 新增单账号写入接口 `POST /api/users { user, createOnly }` 与存档专用 `PATCH /api/users { username, meta }`；新增删除接口 `DELETE /api/users?username=`。
- 新增迁移 `supabase/migrations/0002_leaderboard.sql`（scores 表 + RLS 只读 + Realtime 广播 + `submit_score` 函数）与 `0003_password_hash.sql`（新增 `password_hash` 列）。

### 调整

- **密码不再明文落库**：改为 `pbkdf2$sha256$120000$<盐base64>$<哈希base64>`（每账号 16 字节随机盐，Node `crypto` 与前端 Web Crypto 同格式）。库里 `admin` / `testa` 等老账号在**首次登录成功时原地升级**，明文列随即置空，无需手工洗数据。
- `GET /api/users` 不再返回整表与密码：不带参数只做探活（`{ ok: true }`），带 `?username=` 返回单个账号的 `username` 与 `meta`。
- **存档写入由「整表覆盖」改为按账号粒度**：原先的 POST `{ users: [...] }` 会先 upsert 全部再删掉库里多余的账号，多人同时在线时会互相删存档，现在直接返回 400 拒绝。
- 登录流程改动：`login()` 改为异步（在线走服务端校验，本地通道自行比对并在命中明文时升级为哈希）；注册由数据库主键原子判重，并发注册同名账号不再互相覆盖；`loadUsers()` 不再拉全表，只探活后端并确定通道。

### 修复

- 修复多人同时游玩时存档被对方覆盖的问题（整表覆盖 → 按账号写入）。
- 修复排行榜可能被更低波次覆盖、以及同分排序不稳定的问题（`best_wave desc, updated_at asc`）。

### 验证

- `node --check` 通过（`js/game.js` / `server.js` / `api/users.js` / `api/leaderboard.js`）。
- 账号接口 25 项断言全通过：探活、单账号读取不含任何密码字段、明文老账号登录并升级为哈希且存档无损、错误口令 401、不存在账号 401（不泄露是否存在）、注册落盘无明文且同口令两次哈希不同、重复注册 409、注册缺密码 400、PATCH 存档不破坏密码、删除后登录 401。
- 线上 PostgREST 9 项断言全通过：`submit_score` 首次写入、低波次不覆盖、高波次覆盖、负数不覆盖、按波次倒序、清理后榜单为空。
- 浏览器端到端：UI 注册 → 刷新自动恢复登录态 → 退出 → 错误口令提示 → 正确口令登录；改存档后服务端读回一致；`localStorage` 只有 `fury_current_user`、无 `fury_users`（确认走在线通道）。排行榜页实测渲染「1 好友小狐 31 / 2 admin 27」且当前账号高亮，未配 Realtime 时正确降级为轮询提示。
- 视觉回归 `tests/visual-smoke.html` 180 帧混战 40 项检查通过，无 error / warn。
- Supabase schema 复核：`scores` 与 `users` 均 `rls = true`；`anon` / `authenticated` 在 `scores` 上只剩 `SELECT`（默认授予的 TRUNCATE 等已收回）；`scores` 已加入 `supabase_realtime` 发布。

## v1.0 · 2026-09-17 —— 飞剑体系重做、镰刀「可攻可防」、武器调优

### 新增

- **飞剑 · 巨剑术**（飞剑线专属卡，整条线仅一张）：飞剑体型 +50%、伤害 +30%，**剑身判定半径同步放大（10 → 15）**，剑身碰到的敌人都会受伤，渲染整体缩放。

- **飞剑 · 护身剑阵**：小队 80px 内出现敌人时，在外追击的剑立刻放弃远处目标回身护主（不打断正在进行的贯穿滑行），剑身外圈闪一圈蓝环。
- **飞剑 · 贯穿打击反馈**：命中留下沿剑身方向的细长白光 + 扩散冲击圈（0.2s 淡出），并触发 0.02s 顿帧（节流 0.25s）+ 轻微震屏。
- **镰刀 · 饮血 +10%**（最多 2 张）：镰刀造成伤害的 10% 回复队伍生命，作为「可攻可防」进化线的铺垫卡。

### 调整

- **飞剑：从「周期射出子弹」重做为常驻剑体**
  - 在视野内（300）的敌人之间穿梭贯穿；无敌人时**剑尖朝下绕角色环绕**（半径 48 · 2.0 rad/s，多柄按 2π/柄数 均匀分布）。
  - **惯性滑行**：贯穿后沿剑尖继续滑出 0.22s（保留 72%~100% 速度），滑出约 100px 再折返；折返时机按「剩余冷却刚好够冲回去」反推，保证每次贯穿都结算伤害、不空穿。
  - 基础值 15 伤害 / 1.1s → **9 伤害 / 0.6s**，飞行速度 380（原 430），索敌 300。
- **飞剑：多柄目标从「硬占位」改为「软避让 + 节奏错峰」**
  - 硬性「同一敌人只归一柄」会让剑在敌人少时干等；改为：索敌优先挑 0.35s 内没被任何飞剑穿过的敌人，多柄初始冷却按柄序等分错峰，敌人少时允许集火。
  - 实测：1 敌 3 剑 44.1 DPS（4.9 次/秒 = 冷却上限），5 敌围拢时每趟平均命中 1.56 只。
- **镰刀：修正几何，消除贴身盲区**
  - 环绕半径 70 → **52（固定）**、「变大」卡不再把环推远（只放大刀刃与判定 ×1.3）、判定半径 **24**、每敌受击冷却 0.25s → **0.16s**。
  - 原因：原设计下刀刃绕 70 环、每圈只扫到一次，贴身（<44px）与远距（>96px）都打不到，实测单刃单体只有 6 DPS。
  - 效果：有效范围变为约 14~90px，贴身 25px 从 **0 → 15.3 DPS**，环上 17.3 DPS，5 敌围拢 80.7 DPS。
- **进化 · 死神镰刀 改为「可攻可防」形态**
  - 前置：镰刀击退 + 变大为「**饮血 ≥1 张 + 阻挡子弹 ≥1 级**」；效果改为 数量 +2、伤害 +40%、**吸血 30%**、**子弹碰到刀刃即被斩落**（从 45% 概率改为确定性）。
- **散弹：弹丸更多、单发更弱、总伤害更高**
  - 3 发 × 8 伤害 → **5 发 × 6 伤害**（单轮 24 → 30）；新增 **110px 处收束射界**与弹丸横向错开 5px；整轮共用一次散布（0.5 → 0.28）。
  - 原因：弹丸原本平行错开射出，弹丸越多外侧越偏离，拿「弹丸 +5」卡后贴脸 DPS 反而从 25.8 掉到 22.2，与「弹丸更多 = 总伤害更高」相反。
  - 距离衰减 110→250（×1.4 / ×0.7）→ **110→170（×1.4 / ×0.35）**，保持近战定位。
  - 效果：贴脸 23.1 → **30.8**，远距 7.9 → 9.3；拿弹丸卡后贴脸 22.2 → **51.9**。
- **机枪伤害 6 → 7**（DPS 16.4 → 19.1），与其他三把武器收敛到 17~20 的区间。

### 修复

- 飞剑角度差取模在角度累积偏大时会算出超出 ±π 的差值，导致剑乱转；改用 `atan2(sin, cos)` 求最短夹角。
